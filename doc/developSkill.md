# Develop Skill 

## what are always needed: 
1. when developing a feature, you should always write tests to try to verify the feature if possible
2. sometimes the discussion or the repeat of your understanding are required but it depends.
3. when a feature is done, tests all passed, then should update related stale docs, if no existing ones, should create new one and log important thing down.
4. when using git to commit please commit development in a commit or in a batch of commits; And then do commits for the testings changes, don't mix them; Notes updates or loggings should be in a / a batch of commits as well, don't mix with previous 2(development or testings)
